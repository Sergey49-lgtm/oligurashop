# Проверка правописания

Веб-приложение: вставляете текст, программа проверяет орфографию, грамматику, пунктуацию, стиль и логику,
подчёркивает ошибки и предлагает исправления. Работает в браузере, без сервера и сборки: достаточно открыть `index.html`.

## Как пользоваться

1. Вставьте текст и нажмите **Проверить** (или Ctrl+Enter).
2. Ошибки подчёркиваются цветом:

   | Подчёркивание | Категория |
   |---|---|
   | красная волна | орфография |
   | синяя волна | грамматика |
   | оранжевая волна | пунктуация |
   | фиолетовый пунктир | стиль |
   | зелёная двойная линия | логика и смысл |

3. Нажмите на подчёркнутое место: появится объяснение и варианты исправления. Можно исправить или пропустить.
   Справа есть список всех замечаний.
4. **Исправить всё** применяет первый предложенный вариант ко всем ошибкам. Логические замечания,
   которые нельзя исправить автоматически, останутся в списке для ручной правки.
5. **Скопировать текст** копирует исправленный текст, **Редактировать** возвращает в режим правки.

## Чем проверяется

| Источник | Что находит | Условия |
|---|---|---|
| Встроенные правила (`checker.js`) | частые ошибки («пошол», «вообщем», «здраствуйте», «ихний»…), повтор слов, лишние пробелы, пробел перед знаком препинания и его отсутствие после, строчная буква в начале предложения, дефис вместо тире | всегда, без интернета |
| [LanguageTool](https://languagetool.org) | орфография по словарю, грамматика, пунктуация; русский, украинский, английский, немецкий и др. | бесплатно, нужен интернет; до 20 запросов в минуту, длинный текст делится на части |
| Claude (Anthropic API) | логика и смысл (противоречия, неверные выводы), стиль, сложная пунктуация и согласование; даёт общий вывод по тексту | нужен ключ API, проверка платная; включается в настройках |

Ключ Anthropic хранится только в браузере (localStorage) и отправляется напрямую в API Anthropic.
Модель — `claude-opus-5`, ответ приходит в строгом JSON по схеме, при отказе модели запрос автоматически
повторяется на резервной модели.

Замечания всех источников объединяются: дубли убираются, при пересечении остаётся более важное
(орфография → грамматика → пунктуация → логика → стиль). Логическое замечание к целому предложению,
в котором есть и другие ошибки, остаётся в списке без подчёркивания.

## Запуск

```bash
npm start      # http://localhost:8080
npm test       # тесты ядра (Node.js 18+)
```

Файлы: `index.html` — разметка, `style.css` — оформление (светлая и тёмная тема), `checker.js` — ядро проверки
без зависимостей, `app.js` — интерфейс, `tests/` — тесты.
