# Калькулятор пенсии МВД

Веб-приложение для расчёта пенсии за выслугу лет сотрудников органов внутренних дел РФ.
Работает полностью в браузере, без сервера и сборки: достаточно открыть `index.html`.

## Что учитывает

| Параметр | Значение по умолчанию (2026) | Норма |
|---|---|---|
| Оклад по должности и по специальному званию | вводит пользователь | ст. 43 Закона № 4468-1 |
| Надбавка за стаж службы | 10 / 15 / 20 / 25 / 30 / 40 % по стажу 2 / 5 / 10 / 15 / 20 / 25 лет | ч. 7 ст. 2 247-ФЗ |
| Понижающий коэффициент | 93,59 % (с 01.01.2026) | ст. 43 Закона № 4468-1 |
| Выслуга 20+ лет | 50 % + 3 % за каждый год сверх 20, не более 85 % | п. «а» ст. 14 |
| Смешанный стаж | 50 % + 1 % за каждый год сверх 25 (стаж 25+, служба 12,5+, возраст 45+) | п. «б» ст. 14 |
| Расчётный размер пенсии (РРП) | 9 513,42 ₽ (оценка на 01.04.2026: 8 907,70 × 1,068) | ст. 46 |
| Надбавка на иждивенцев | 32 / 64 / 100 % РРП | п. «в» ст. 17 |
| Инвалид I группы / 80 лет | 100 % РРП | п. «а» ст. 17 |
| Ветеран боевых действий | 32 % РРП | п. «г» ст. 17 |
| Районный коэффициент | 1,0–2,0 | ст. 48 |

Формула:

```
Пенсия = [(оклад по должности + оклад по званию) × (1 + надбавка за стаж)
          × понижающий коэффициент × процент за выслугу
          + надбавки от РРП] × районный коэффициент
```

Дополнительно:
- прогноз «если послужить ещё 1–5 лет»;
- поле «индексация окладов» — например, 4 %, чтобы увидеть пенсию после индексации с 1 октября 2026 года;
- все коэффициенты можно изменить, когда выйдут новые значения;
- введённые данные сохраняются в браузере, расчёт можно распечатать;
- тёмная тема и мобильная вёрстка.

Расчёт ориентировочный. Точный размер пенсии определяет пенсионное подразделение (ЦФО) МВД.

## Запуск

```bash
# открыть файл напрямую
xdg-open index.html

# или через локальный сервер
npm start          # http://localhost:8080

# тесты расчётного модуля (Node.js 18+)
npm test
```

## Структура

- `index.html` — разметка формы и результата
- `style.css` — стили (светлая и тёмная темы, мобильная вёрстка)
- `calc.js` — расчётный модуль без зависимостей (браузер и Node.js)
- `app.js` — связь формы с расчётом, сохранение ввода
- `tests/calc.test.js` — модульные тесты
